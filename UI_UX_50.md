# UI and UX review: 50 checks

This checklist records the scope of the UI review. Items describe implementation or existing behavior reviewed in source; visual and device checks remain necessary before calling the review complete.

1. Keep the header visible during scrolling.
2. Keep the brand readable on narrow screens.
3. Give the language selector a comfortable touch height.
4. Give the enquiry button a comfortable touch height.
5. Highlight the current desktop navigation section.
6. Provide a skip-to-content link for keyboard users.
7. Prevent sticky navigation from hiding section headings.
8. Keep the hero photo visible on mobile.
9. Retain sufficient text contrast over the hero photo.
10. Balance hero heading line breaks.
11. Improve hero description line spacing.
12. Keep mobile hero actions side by side when space permits.
13. Offer direct call and WhatsApp contact.
14. Keep service section heading and description aligned.
15. Ensure service titles wrap within their cards.
16. Improve service description line spacing.
17. Keep service links separated from descriptions.
18. Indicate that service cards can be browsed horizontally.
19. Provide previous and next service controls.
20. Give carousel controls touch-friendly targets.
21. Keep product cards visually consistent.
22. Improve product title wrapping.
23. Improve product description readability.
24. Keep product enquiries easy to find.
25. Preserve the original product images.
26. Offer a full-photo view for product images.
27. Provide photo navigation controls for multiple images.
28. Show the current photo number.
29. Support swiping between full-size photos.
30. Support keyboard navigation in the photo viewer.
31. Restore focus after the photo viewer closes.
32. Improve product card hover feedback on pointer devices.
33. Make the reasons section easy to scan.
34. Present the product range photograph with rounded corners.
35. Give the map an accessible title.
36. Keep the directions link clearly identifiable.
37. Provide a visible focus indicator on the map link.
38. Use expandable questions to reduce scrolling.
39. Improve FAQ spacing and readability.
40. Keep contact numbers accessible in the footer.
41. Give footer links clear focus and link states.
42. Provide a back-to-top link.
43. Open the enquiry form in a modal.
44. Label enquiry fields in English and Marathi.
45. Validate required fields and the ten-digit phone number.
46. Accept Devanagari numerals in the phone field.
47. Provide a clear WhatsApp handoff and fallback link.
48. Ensure form controls use a readable mobile font size.
49. Respect reduced-motion preferences.
50. Account for mobile bottom safe areas and persistent contact controls.

Verification: production build required; mobile and desktop visual, keyboard and device testing are not implied by this source checklist.
